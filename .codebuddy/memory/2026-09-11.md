# 2026-09-11

## 把项目改写为 Vite 工程 + 新增「口算擂台」

- 原三文件静态站（index.html / style.css / script.js）已重构为 Vite 项目，旧的 `style.css`、`script.js` 已删除。
- 新结构：
  - `src/main.js` 入口装配（引样式、初始化各模块、主题切换）
  - `src/core/` 纯逻辑，不碰 DOM：`expression.js`（tokenize + 递归下降求值 + formatNumber）、`hash.js`（自写 MD5 + Web Crypto SHA）、`storage.js`（localStorage 封装）
  - `src/app/`：`keyboard.js`（优先级键盘路由）、`calculator.js`、`hashPanel.js`
  - `src/game/`：`generator.js`（出题）、`engine.js`（状态机计分）、`panel.js`（界面）
  - `src/styles/`：`base.css`、`calculator.css`、`modal.css`、`game.css`
- 关键技术点：新增 `app/keyboard.js` 优先级键盘路由（游戏 30 > 弹层 20 > 计算器 10），替代原先靠判断全局 modal 状态来拦截键盘的写法。
- 口算擂台玩法：4 个关卡（20 以内加减 / 九九乘除 / 四则混合 / 两位数挑战）；限时 60~90 秒、3 条命；答对基础分 = 星级×10，连击加成每题 +2（上限 +20），3 秒内作答手速 +5；答错扣命并清零连击；跳过扣 5 秒。最佳成绩按关卡存 localStorage（键 `mathgame.best`）。
- 出题铁律（generator.js）：答案必须非负整数；除法一律「先定除数与商再相乘」保证整除；摇出非法题就重试（最多 30 次）。
- 验证结果：`npm run build` 通过（17 模块，css 19.31KB / js 20.74KB）；自测 4 关卡 × 3000 题无一道非法；MD5 四个标准向量（含中文）全部匹配；dev server 返回 HTTP 200。
- 环境：Vite 8.3.0、Node v25.6.0、npm 11.10.0。
